# 功能需求

- 智能体逻辑改造，数据采用实时查询方式，不存储到数据库，
- web页面升级改造，支持智能咨询tab和大盘指数展示tab,
- 智能体页面有查询数据选项，近3天，近10天，近一月，近2月，近3月，近一年，自定义选项，当用户输入查询问题时，如何设计到大盘相关的问题就默认实时查询近三十天的数据喂给ai，给ai 的数据保持不变，只是从原来查询本地数据库变为实时查询，如果用户选择了时间限制，则用用户选择的时间

- 大盘指数页面，实时查询字段展示，字段跟当前数据库里的一样，只是变为实时查询，同样也支持近3天，近10天，近一月，近2月，近3月，近一年，自定义选项，默认展示近30天，但是当天的数据要间隔5分钟刷新一次，举个例子，如果今天是交易日，那么今天我进入页面后，关于今天的数据信息都要定时5分钟更新一次
