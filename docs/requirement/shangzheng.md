# 功能需求
基于langgraph创建一个智能体，智能体的功能主要如下：
1. 设计一个数据库，数据库字段指数名称、指数数值、日期、相较于上一个交易日涨跌值、相较于上一个交易日涨跌原因(这里的原因要基于当时的社会背景，经济状况， 热点问题等分析)
2. 首先获取指上证指数和创业版指数近1年的数据存入数据库，每天的指数值都要查询网站分析涨跌原因并存入数据库
3. 每个交易日下午2点自动获取大盘数据 指上证指数和创业版指数，分析相较于上一个交易日的涨跌值和原因存入数据库
4. 智能体分析下一个交易日涨跌，这里只有第一次需要大模型分析全量数据，分析完后做成一个长期记忆存入数据库，下一次大模型分析只需要基于上一次的分析结果再结合当天的数据分析就行
5. 分析好数据后将下一个交易日买涨还是买跌通过消息通知到我的手机，通过短信的方式通知，手机号15136489941，注意我只买指数基金，即上证指数和创业板指数
