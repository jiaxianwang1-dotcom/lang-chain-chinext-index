# 预测模型优化总结（2026-06-07）

## 背景

基于 `2026-0607.md` 中的回测分析，6月5日对上证指数和创业板指的预测均失败：
- **上证**：预测 hold(+0.00%)，实际 -0.74% —— 低估了技术面空头与外部负反馈的共振
- **创业板**：预测 hold(+0.00%)，实际 -3.20% —— 严重低估了资金面持续恶化的杀伤力

核心问题：**模型面对多维度同向恶化信号时，仍倾向于给出 neutral/hold，未能识别资金出逃主导的破位风险。**

---

## 优化内容（v4）

### 1. 预计算信号评分系统（代码层量化，不依赖 LLM 主观判断）

新增三核评分，范围 `-3 ~ +3`：

| 评分维度 | 核心输入 | 看空阈值 | 看多阈值 |
|---------|---------|---------|---------|
| **资金面（fundFlow）** | 融资5日累计净买入、期货升贴水、量比 | 5日净卖出>200亿 → -2.0；连续3日净卖出 → 额外-0.5；期货2+贴水 → -1.5；缩量下跌 → -0.5 | 5日净买入>200亿 → +2.0；期货2+升水 → +1.0；放量上涨 → +0.8 |
| **技术面（technical）** | 均线排列、MACD、RSI、布林带、缺口、连涨连跌 | 空头排列 → -1.5；MACD死叉+绿柱 → -1.0；跌破下轨 → -0.5 | 多头排列 → +1.5；MACD金叉+红柱 → +1.0；突破上轨 → +0.5 |
| **外部市场（external）** | CNH、恒指、恒生科技、ETF | 恒指-2% → -1.5；CNH贬值>0.3% → -0.8 | 恒指+2% → +1.5；CNH升值>0.3% → +0.8 |

**信号共振判定（resonance）**：
- `strong_bear`：≥2个核心维度强烈偏空，或资金面≤-2且另有维度偏空
- `bear`：≥2个核心维度偏空，无多头对冲
- `strong_bull` / `bull`：同上逻辑，方向相反
- `conflict`：核心维度多空互现
- `neutral`：信号平淡

### 2. System Prompt 规则强化

#### hold 条件收紧
- **只允许在 `conflict` 或 `neutral` 时给 hold**
- 当 resonance 为 `strong_bear` / `bear` / `strong_bull` / `bull` 时，**禁止 hold**，必须给出对应方向

#### 资金面破位专项规则
- **三杀信号**（必须同时满足）：融资5日累计净卖出>100亿 + 期货2+合约贴水 + 量比<0.9 → **必须看空，confidence ≥ 0.72**
- **资金抢筹信号**：融资5日累计净买入>100亿 + 期货2+合约升水 + 量比>1.2 → **必须看多，confidence ≥ 0.72**

#### 置信度梯度校准（v4）
| 场景 | confidence 范围 |
|-----|----------------|
| strong_bear / strong_bull 共振 | 0.78 – 0.90 |
| bear / bull 共振 | 0.68 – 0.78 |
| 多维度一致但信号温和 | 0.60 – 0.70 |
| 主导维度不足 / 非核心冲突 | 0.55 – 0.65 |
| conflict / neutral / 缺维度≥4 | 0.50 – 0.58（hold） |

#### 异动信号增强
新增以下专项提醒：
- **量比<0.9 + 指数下跌 + 期货贴水** → 缩量阴跌，机构避险，破位风险高
- **融资连续3日以上净卖出 + 累计>50亿** → 杠杆资金撤退，看空信号
- **期货全面贴水（IF+IC+IM 同时 basis_pct<-0.3%）** → 机构集体看空远期
- **恒指当日-2%以上** → 港股暴跌传导A股，强烈谨慎
- **均线空头排列 + MACD绿柱 + 缩量** → 三重空头确认，不要轻易抄底

### 3. User Prompt 增强

在维度10之后新增**预计算信号评分板块**，以可视化条形图形式展示三核评分和共振结论：

```
资金面评分: ░░██████ -2.5 | 技术面评分: ░░██████ -1.8 | 外部市场评分: ░░░░████ -1.2
信号共振结论: strong_bear —— 强烈看空共振：资金面-2.5分/技术面-1.8分/外部-1.2分，多维度同向恶化，机构避险意愿强烈
说明：负值=看空，正值=看多，绝对值越大信号越强。当 resonance 为 strong_bear/bear/strong_bull/bull 时，禁止 hold，必须给出对应方向。
```

### 4. hold 区间宽度优化

- `volatilityBasedHalfWidth` 新增 `isHold` 模式：hold 时使用更大的 sigma 乘数（`max(0.8, 1.8 - confidence)` vs 方向预测的 `max(0.5, 1.5 - confidence)`）
- hold 区间半宽最小值从 0.3 提升到 **0.4**
- 对于高波动品种（如创业板指，rv≈1.5%），hold 区间将从原来的 ±0.3% 扩展到 **±1.2%~±1.5%**，更符合实际波动
